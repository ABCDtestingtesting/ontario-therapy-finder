# Psychology Today competition measurement: 2026-11-23 to 2026-11-29 (Toronto)

Scope: exactly the 60 FSAs in research/pt_candidates_2026-11-24.csv. The Google figures are preliminary, not individual therapist counts. Primary outcome is unique active therapist profiles eligible for an FSA's search, including remote advertisers; secondary outcomes are visible profiles in a standardized search, adult-therapy visibility and residents per visible profile. Do not treat an office address as proof of eligibility.

## Evidence
1. Preferred source: ask PT support for an aggregate exact active therapist profile count per FSA, explicitly including target listing areas, excluding treatment centre/group directory categories, with date and inclusion definitions. Also request weekly FSA searches if available. A member dashboard is not assumed to expose market counts.
2. With permission, sample the normal Canadian directory's client-facing FSA results on at least three separate dates, using identical unfiltered conditions, and a distinct adult-filtered comparison if supported. Record first page and every reachable page, timestamps and stable profile IDs, not displayed totals. Keep repeated profiles once per FSA per survey. Compare list/map only if both include the same online and in-person population. Never circumvent rate limits or access controls.
3. An authorized profile-location export provides independent reverse mapping from active profile ID to advertised FSA; do not infer advertised areas from office addresses, search-engine snippets or a generic serves-area label. Compare profile-derived memberships with search appearances.
4. Third-party indexed pages and official regulator registries can corroborate identities or physical addresses. Neither proves active PT targeting this week. Indexed evidence is dated separately and cannot fill a missing live observation.
5. Ranking: exact active profile count only from an authoritative documented count/export. Otherwise show union of unique observed IDs and repeat-search count variability; unobserved profiles remain possible. Keep incomplete/blocked/old observations separate. Never rank a missing source as zero. Report raw profile count and per-10,000 census residents separately; population is an approximation to demand. First-page appearances are a separate exposure metric.
6. Verify capture dates, query scope, terminal pages, page hashes, duplicate IDs, repeated scans and discrepancies. Do not promise a complete seven-day snapshot before November 29. No automated directory scraping absent express authorization (PT terms section on prohibited use).
