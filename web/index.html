4. Rank neighbourhoods and export
The program scores sampled residential locations within each postal area. It treats local Psychology Today postal listings as an observed directory measure, not proof of in-person availability. It calculates estimated 2021 population and Google-mapped therapy locations within 5 km, and displays Psychology Today competition separately. It also identifies two sufficiently separated candidate areas when available.
